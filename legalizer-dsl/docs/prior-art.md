# 规则引擎里值得借的，和不该借的

写这份东西只有一个目的：把"我们不是在发明语言"说清楚。每条设计决定，
要么能在已有系统里找到先例，要么能说清楚为什么不借。按"借什么 / 不借什么 /
为什么"三列记。

## 一、词法/语法工具：lex/flex、yacc/bison

| 机制 | 在那边是什么 | 在我们这里是什么 |
| --- | --- | --- |
| 命名定义（lex `DIGIT [0-9]`） | 复用一个正则片段 | `group pair = 0, 1;` 复用一个槽位集合 |
| 起始条件（lex `%x`、`BEGIN(SC)`、`<SC>rule`） | 规则只在某个状态里生效 | `with pair { ... }`：块内省略的槽位 = 这个集合；块外不受影响 |
| 优先级声明（yacc `%left` / `%nonassoc`） | 冲突按声明消解，不是按出现顺序 | 特指 > 默认；同槽同类的两个特指是 `%nonassoc`，**报错**，不是"后写的赢" |
| 冲突门禁（bison `-Wall`、`%expect 0`） | 文法冲突数必须为 0 | `check_grammar.sh` 断言 bison 0 error / 0 warning / 0 conflict |
| 模式-动作（lex `pattern action`） | 匹配到什么就做什么 | `except 谓词 -> legal / custom / lower / libcall / unsupported` |

借这三样，是因为它们都是**小机制**：作用域、命名、冲突消解。它们不引入
求值模型，所以能和"规则链是有序的"这一点共存。

不借：最长匹配、回溯、正则优先级。类型不是字符串，`v4s32` 是一个结构化
对象，不是"能匹配上的最长前缀"。

## 二、产生式系统：Rete / Phreak（Drools、CLIPS、Jess）

Rete 的核心是把规则编译成一张判别网络：alpha 网络做**每个属性上的测试**，
beta 网络做**跨条件连接**，测试在规则间共享，并按选择性排序。

我们的查表就是 alpha 网络：键 = (opcode, 每槽的等价类)，格子 = 答案。
"先按最粗的轴切、再按细的轴切"和 Rete 的测试排序是同一个优化问题。

借：
- 测试共享（同一槽的划分只算一次）；
- 选择性优先（先切区分度大的轴）；
- 编译期把谓词链折叠成表（我们已经在做）。

不借：
- 增量匹配 / 事实撤回（我们的查询是纯函数，没有 agenda）；
- 冲突消解策略（salience、recency）。那是可编程的调度器，我们需要的是
  一个能证明的偏序，不是一门调度语言。

## 三、策略引擎：XACML 3.0、Cedar、CSS 级联

这三家都在解决同一个问题：多条声明同时适用时，谁说了算。

| 系统 | 组合规则 | 我们借到的 |
| --- | --- | --- |
| XACML | deny-overrides / permit-overrides / first-applicable，规则显式命名 | 组合规则必须**有名字**，不能是"实现里碰巧这样" |
| Cedar | forbid 优先于 permit | 优先级是一个小格（lattice），不是一张可编程的表 |
| CSS 级联 | specificity → source order → `!important` | 优先级 = (特指程度, 书写顺序)；但我们拒绝 CSS 的"静默覆盖" |

我们的规则：**不写槽位 = 默认规则；写槽位 = 特指；特指赢。**
同槽同类出现两个特指，是错误（`13-policy-duplicate`），不是后者覆盖前者
——CSS 的静默覆盖是这套模型里最出名的坑。

## 四、不动点：Datalog / Soufflé

legalizer 不是一次翻译，是 `Reach = lfp(Seeds, T)`：第 k 步的结果重新
进入第 k+1 步。这和 Datalog 的半朴素求值、分层否定是同一个形状。

借：
- 终止性要有良基度量（我们的度量是"类型在宽度/形状格上严格上升"）；
- 环用 SCC 报告（`infer_diff` 已经在报 cycle）；
- 分层：查询谓词和特性谓词分开算（我们按 feature assignment 冻结一次）。

不借：通用归结/回溯。规则链是**有序**的，改成搜索会改变语义。

## 五、默认值与完备性：CUE / Dhall、有限商

CUE 的默认值要求"统一后仍然是一个值"，即默认是**全函数**且幂等。
我们的 `policy` 是同一个要求：`policy*` 必须把每个可达类型送到
`legal ∪ escape`，且再走一步不动。

"有限商"那一套（等价类 + 代表元 + 边界点）对应的是组合测试里的
equivalence partitioning / covering array：在有限键域上，全枚举和
"每类一个代表 + 每个断点 ±1"是等价的。这条是我们敢说"8196 个类型里
543 个边界点就够"的依据，也是 `tools/rule_atoms.py` 的 shape/atoms/grid
三条判据的来源。

## 六、一句话版本

借**作用域、命名、优先级、冲突门禁**（lex/yacc），借**测试共享与选择性**
（Rete），借**组合规则要有名字**（XACML/Cedar），借**良基度量与 SCC**
（Datalog），借**默认必须全且幂等**（CUE）。不借调度器、不借回溯、
不借静默覆盖。
